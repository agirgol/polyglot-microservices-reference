# ADR NNNN: Title, as a decision rather than a topic

**Status:** Proposed | Accepted | Superseded by ADR-NNNN
**Date:** YYYY-MM-DD

## Context

What forced a choice. The constraint, the requirement, or the thing that broke.
Written so someone who was not there can tell whether the constraint still
holds — because when it stops holding, this decision should be revisited.

## Decision

What was chosen, in one or two sentences, in the active voice.

## Consequences

What this costs, not only what it buys. An ADR that lists no downside is
advertising. Include what becomes harder, what is now locked in, and what would
have to change to undo it.

## Alternatives considered

Each one named, with the reason it lost. "We did not evaluate X" is a legitimate
entry and more useful than silence — it tells a reader the option is open rather
than closed.
